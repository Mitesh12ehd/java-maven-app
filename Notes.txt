Complete CI/CD:

    Increment version > Build app > Build image and push to repo > Deploy to K8s cluster 
    > Commit version update

    - check Project java-maven-app jenkins-practice branch

Deploy:
    - when new version updates, we need to create new deployment and service
    - create deployment and service yaml file

    Image version:
        - we are using new docker image every time pipeline runs

How to pass environment variable from our Jenkins file to K8s configuration file:
    - envsubst tool
    - we need to install inside jenkins container

    Install tool envsubst:
        - enter as root user inside container
        - apt-get install gettext-base
        - envsubst subset is tool that is present inside gettext-base

        - sh "envsubst < kubernetes/deployment.yaml | kubectl apply -f -"
          sh "envsubst < kubernetes/service.yaml | kubectl apply -f -"

    - it replace all the environment variable with its value
    

Fetch image:
    - k8s cluster must allow to fetch the image from docker repository
    
    Configure docker hub credential:
        - use Secret
        - Create secret in eks cluster only once
        - it doesn't create every time pipeline runs
        
        kubectl create secret docker-registry my-registry-key \
        --docker-server=docker.io \
        --docker-username=miteshch \
        --docker-password=xyz
